# باسل مؤنس — صدقة جارية

موقع ثابت بالعربية لجمع تلاوات وخطب ودروس المهندس باسل مؤنس رحمه الله.

## إضافة مادة للجميع

افتح `catalog.js` وأضف سطرًا:

```js
{ id: "VIDEO_ID", title: "خطبة الجمعة — العنوان", kind: "lesson", duration: "20:00" }
```

`kind` يكون `tilawa` أو `lesson`. معرّف الفيديو هو الجزء بعد `v=` في رابط يوتيوب.

نموذج الإضافة داخل الموقع يحفظ الرابط على جهاز الزائر فقط. للنشر العام عدّل `catalog.js` ثم أعد الرفع.
